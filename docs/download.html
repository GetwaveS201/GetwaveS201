🚀 Quick Start Instructions

  1. Download both workflow files using the buttons above
  2. Install n8n: npm install n8n -g
  3. Start n8n: n8n start
  4. Import workflows: Click "..." menu → "Import from File"
  5. Configure credentials: Gmail OAuth2 + API token
  6. Activate workflows: Toggle "Active" switch

💡 Pro Tip: After importing, update the API URLs in both workflows to point to your backend server. Replace https://YOUR_API_URL with your actual URL (e.g., http://localhost:8000 for local testing).
