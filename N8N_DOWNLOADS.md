## ⚡ How to Use (3 Steps)

### Step 1: Download
Click one of the links above → File will download

### Step 2: Import to N8N
1. Open N8N: https://app.n8n.io
2. Click **Workflows** (left sidebar)
3. Click **Import from File**
4. Select the JSON file you downloaded
5. Done!

### Step 3: Configure
Set up 3 credentials in N8N:
- **MongoDB**: Your database connection
- **OpenAI**: Your GPT-4 API key
- **SMTP**: Your email settings

Then click **Execute Workflow** to test!
